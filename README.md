## 🚀 Featured Project

### 1. Aplikasi Penggajian Karyawan

Aplikasi berbasis web dan mobile yang dikembangkan untuk membantu proses pengelolaan data karyawan dan perhitungan gaji secara lebih terstruktur.

**Teknologi yang digunakan:**
- PHP
- MySQL
- HTML
- CSS
- JavaScript

**Fitur utama:**
- Login dan autentikasi pengguna.
- Pengelolaan data karyawan.
- Pengelolaan gaji karyawan.
- Perhitungan gaji dan total penghasilan.
- Pengelolaan gaji lembur (*overtime*).
